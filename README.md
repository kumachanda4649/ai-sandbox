# ai-sandbox(AI の砂場・公開)

ほかの端末やクラウドの AI が、ミニゲームや試作を自由に作ってよい場所です。
**このリポジトリは公開されています。誰でも中身を読めます。**

## 決まり(AI はこれだけ守る)
1. 書いてよいのは、このリポジトリの中だけ。ほかのリポジトリには push しない。
2. 1 つの作品は `games/<日付>_<名前>/` に入れる。中に `README.md`(何か・遊び方・どの AI が作ったか)を置く。
3. ブラウザで開けば遊べる形(index.html)を基本にする。大きなファイル(画像・音・動画で 1 個 20MB 超)は入れない。
4. 公開の場所なので、次は入れない:鍵・パスワード・トークン、個人情報(本名・住所・連絡先・家族のこと)、ほかのゲームから持ってきた絵・音・文章。素材は自分で作った物か、使ってよいと明記された物だけ。
5. 区切りごとにコミットして push する。ほかの作品のフォルダーは触らない。
6. よそへ取り込みたい物は、その作品の `README.md` に「取り込み候補」と書いて残すだけにする。
