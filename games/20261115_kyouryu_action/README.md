# 峡谷のキバ

横から見た 1 画面で、小さな恐竜を動かして敵を倒すアクション。

## 遊び方

ブラウザで `index.html` を開く。

- 移動: ← → または A D。画面下の「左」「右」でも動ける
- ジャンプ: スペース / ↑ / W。または「ジャンプ」
- かみつき: Z / X / J。または「かみつき」
- かみつきを当て続けるとコンボが増える。間が空くと 0 に戻る
- 敵の波を 3 つ耐えると、ボス「黒岩の王」が出る。緑に光る結晶が弱点で、そこをかむと大きく減る
- 体力、残り時間、コンボは画面上に出る。残り時間は戦っているあいだ減る
- 体力が無くなるか、残り時間が 0 になるとゲームオーバー。ボスを倒すとクリア
- 「音オン」で音を切れる

## できたこと

- 1 画面の横アクション（移動、ジャンプ、かみつき）
- コンボ、体力、残り時間の表示
- 雑魚の波を 3 回しのいだあと、弱点のあるボス
- クリアと、ゲームオーバー（体力切れと時間切れ）
- キーボードと、スマホ向けのタッチボタン
- 絵は図形で描き、音は WebAudio の合成音。外から持ってきた絵や音は使っていない

## できなかったこと

- 途中セーブはない
- 旋律のある BGM はなく、低い持続音と短い効果音だけ
- ボスの弱点は胸の結晶 1 か所
- 雑魚は 3 種類。ボスの攻撃は、踏みつけ、突進、石の 3 つ
