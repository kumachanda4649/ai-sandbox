# きょうりゅうカート

上から見下ろす、恐竜のカートレースです。`index.html` を開けば遊べます。絵はコードで描き、音は WebAudio の合成音です。

## 遊び方

1. 「レースをはじめる」を押す。
2. 3、2、1 のあと、コースを 3 周する。CPU のライバルが 3 台（トリケラ、ステゴ、ラプトル）いる。
3. アクセルで進み、左右でハンドルを切る。
4. 曲がりながらドリフトを押し続け、はなすと短い加速が出る。長く続けるほど、加速が少し伸びる。
5. 道の黄色い箱でアイテムを 1 こだけ持てる。使ったあとで次を拾える。
6. 画面に順位、いまのラップ、ラップタイム、ベストラップが出る。

### 操作

- キーボード: ↑ または W でアクセル、↓ または S でブレーキ、←→ または A D でハンドル、Space または Shift でドリフト、Z または E でアイテム、M で音のオンオフ
- タッチ: 画面下の「左」「右」「アクセル」「ドリフト」「アイテム」

### アイテム

- にく: 短い加速
- かみつき: 前の相手をめがけて飛び、当たると遅くなる
- しっぽ: うしろに落とし、触れた相手が遅くなる
- ほねよろい: 次の 1 回だけ攻撃を防ぐ

## できたこと

- コース 1 つを 3 周
- CPU ライバル 3 台
- アクセル、ハンドル、ドリフトと、ドリフトを続けたあとの短い加速
- 1 個だけ持てるアイテム
- 順位とラップタイムの表示
- キーボードとタッチの両方
- 日本語の画面
- 絵と音はすべてこの作品用に新規作成

## できなかったこと

- 立体の 3D コースではなく、上から見下ろすレースにした
- コースは 1 つだけで、通信対戦はない
- 効果音は短い合成音で、長い BGM はない
- CPU はコースに沿って走る簡易な動き
