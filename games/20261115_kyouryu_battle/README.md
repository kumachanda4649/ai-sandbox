# きょうりゅうバトル

## 何か
味方の恐竜3たいと、敵1〜3たいが戦う、ATB（ゲージがたまると行動）のコマンドバトル。
絵はコードで描いたドット絵、音は WebAudio の合成音。外部の絵・音・ライブラリは使っていない。

## 遊び方
`index.html` をブラウザで開く。

1. 「ぼうけんに でる」で第1戦が始まる。敵戦が3回あり、そのあとボス。
2. 各恐竜の ATB ゲージが満タンになると行動できる。味方が行動するあいだ、時間は止まる。
3. わざは「かみつく」「ひっかく」「たいあたり」。相性は次の3すくみ。
   - かみつく は ひっかきタイプに強い
   - ひっかく は たいあたりタイプに強い
   - たいあたり は かみつくタイプに強い
   - 強いとダメージ1.5倍、弱いと0.7倍
4. 「ためる」を選ぶと、次の行動でその恐竜の必殺技を1回出せる。
5. 敵が複数のときは、わざのあとで対象を選ぶ。ボタンに「ばつぐん」と出る相手が有利。
6. 勝つと経験値が入り、レベルが上がる。HP・こうげき・すばやさが増えて、次の戦いの前にHPは全快する。
7. 全滅すると、その戦いだけやりなおせる。それまでに上がったレベルは残る。
8. ボス「マグマオウ」は、HPが減るとタイプが変わる。

操作:
- スマホ: ボタンをタップ。メッセージは「おくり」か画面タップで送れる。
- パソコン: ↑↓ で選び Enter で決定。Esc で対象選択をもどる。1〜5 でコマンド。M で音のオン／オフ。

## できたこと
- ATB のコマンドバトル（味方3たい、敵は1〜3たい）
- かみつく・ひっかく・たいあたりと、ためる必殺技
- 3すくみの相性表示とダメージ倍率
- 経験値とレベルアップ（HP・こうげき・すばやさ）
- 敵戦3回と、タイプが変わるボス
- タッチとキーボードの両方、画面の文言は日本語
- コードで描いた恐竜と、合成音

## できなかったこと
- セーブはない。ページを閉じると最初から。
- 道具、状態異常、「にげる」はない。
- 音は短い効果音と、くり返す簡単な調べ。長い曲にはしていない。
- ボスを早く倒すと、ボス自身の必殺までは出ないことがある。
