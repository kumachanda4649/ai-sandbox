赤外線(せきがいせん)ライトの作りかた

目に見えない光(ひかり)を出すライトを、100円ライトで作ろう。

作りかたの流れ

つぎの4つの章を、じゅんばんに進めます。ぜんぶで 40ステップ。1ステップでやることは1つだけ。

⚠ はじめに読んでね はんだごては、とても熱い(約350℃)。やけどと火事に気をつけよう。 電池の＋と−を、線で直接つなぐと(ショート)、熱くなって火が出ることもある。 → むずかしいときは、先生や大人に聞いてね。
中のつくりは、写真からの予想です。テスターで確かめながら進めよう。

用意するもの(チェックリスト)

部品

  • ダイソー LED LIGHT BLT(金属の筒を外側のケースとして使う) ×1
  • Arduino Pro Mini 5V/16MHz ×1(ピンヘッダはつけない。または線を直接つける)
  • USB-シリアル変換(FTDIなど。プログラムを入れる道具) ×1
  • 単3アルカリ電池 ×3、電池ボックス(3本用・線つき) ×1
  • 赤外線LED 940nm(例:OSI5FU5111C-40、またはリモコンのLED) ×4〜8
  • 抵抗 75Ω ×(LEDの数と同じ)
  • 抵抗 100Ω ×1、抵抗 10kΩ ×1
  • Nch MOSFET 2SK4017 ×1
  • 丸くて小さいユニバーサル基板 ×1
  • 配線用の細い線(赤・黒・そのほか) 少し
  • 熱収縮チューブ または ビニールテープ
  • ホットボンド(グルーガン)

道具

  • マイナスドライバー(小)、ピンセット
  • はんだごて(太いこて先と細いこて先)、はんだ、こて台
  • テスター
  • ニッパー(線を切る道具)、ワイヤーストリッパー(線のカバーをむく道具)

大人の人むけ：プログラム

Arduino Pro Mini(5V/16MHz)用のプログラムです。D9から1秒に4万回(40kHz)のオン・オフを出します。

注意：このコードは、まだコンパイル(パソコンでの変換テスト)をしていません。実機で確かめてください。
// Arduino Pro Mini 5V/16MHz  (ボード: Arduino Pro or Pro Mini, ATmega328P 5V 16MHz)
// D9(OC1A) -> 100Ω -> 2SK4017 ゲート 。D9=HIGH でLED点灯。
// ※未コンパイルです。実機で確認してください。

const uint8_t  FRAME_PERIODS = 33;   // 1フレーム = 40kHz × 33周期
volatile uint8_t idx = 0;

// 周期番号 -> OCR1A (TOP=399 のとき 200=50%)
static inline uint16_t widthFor(uint8_t i) {
  if (i < 8)  return 200;  // フル
  if (i < 12) return 50;   // 1/4
  if (i < 16) return 12;   // 約1/16
  if (i < 20) return 3;    // 約1/64
  return 0;                // 消灯 (13周期)
}

ISR(TIMER1_OVF_vect) {
  uint16_t w = widthFor(idx);
  if (w > 0) {
    OCR1A = w;                 // 次の周期から反映される
    TCCR1A |= _BV(COM1A1);     // 周期のはじめでHIGH、決めた幅でLOW
  } else {
    TCCR1A &= ~_BV(COM1A1);    // PWM出力を切り離す
    PORTB  &= ~_BV(PB1);       // D9をLOWに固定 = LED消灯
  }
  if (++idx >= FRAME_PERIODS) idx = 0;
}

void setup() {
  pinMode(9, OUTPUT);
  digitalWrite(9, LOW);            // 起動中はLED消灯
  noInterrupts();
  // モード14: WGM13:0 = 1110 (高速PWM, TOP=ICR1)
  TCCR1A = _BV(WGM11);
  TCCR1B = _BV(WGM13) | _BV(WGM12) | _BV(CS10);  // 分周なし(16MHz)
  ICR1   = 399;                    // 16MHz / (399+1) = 40kHz
  OCR1A  = 0;
  TIMSK1 = _BV(TOIE1);             // オーバーフロー割り込み
  interrupts();
}

void loop() { /* 何もしない */ }
